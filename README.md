## Sobre o site

Site estático (HTML, CSS e JavaScript puros, sem dependências) publicado pelo GitHub Pages.

- `index.html`: conteúdo da página
- `assets/css/style.css`: estilos, com tema claro e escuro
- `assets/js/main.js`: alternância de tema, menu mobile e filtro de projetos por tema
- `images/projects/`: capas dos projetos padronizadas em 800×450 (WebP)

### Adicionar um projeto

Copie um `<article class="card">` dentro do grupo desejado (`data-group="ia" | "aws" | "ds" | "bi"`),
troque a imagem, o texto e os links, e atualize o contador no botão de filtro correspondente.
