Nuvem AWS

Alta Disponibilidade com Load Balancer e CI/CD

Aplicação full-stack em duas zonas de disponibilidade atrás de um ALB, com HTTPS e deploy automático a cada git push.

  • ALB
  • ECS
  • CodePipeline
  • ECR
  • Route 53
  • ACM
  • RDS
Ver estudo de caso
Problema
Uma única máquina era ponto único de falha, e cada deploy era manual e derrubava o site.
Solução
ALB com target group distribuindo tráfego entre tasks ECS em duas AZs; CodePipeline + CodeBuild publicam a imagem no ECR e atualizam o serviço gradualmente.
Destaques
  • Deploy sem downtime disparado pelo GitHub
  • Domínio próprio com HTTPS (Route 53 + ACM)
  • Ambiente de dev criado com o agente de IA Kiro
Ver no GitHub: Alta Disponibilidade com Load Balancer e CI/CD (abre em nova aba)

Previsão de Vendas de uma Rede de Farmácias

Prevê as vendas das próximas 6 semanas de cada loja Rossmann e entrega o resultado por um bot no Telegram.

~4% de erro na previsão de 6 semanas (loja 286)

  • Python
  • Random Forest
  • Flask
  • Heroku
  • CRISP-DM
Ver estudo de caso
Problema
O CFO precisava definir quanto investir na reforma de cada loja, mas não havia previsão confiável de faturamento.
Solução
Ciclo CRISP-DM completo: engenharia de atributos, Random Forest escolhido entre 6 modelos (média, lineares, Prophet, XGBoost) e API Flask no Heroku consumida pelo bot.
Destaques
  • Modelo em produção, consultado pelo Telegram
  • Insights de sazonalidade (fim de mês, domingos)
  • Cenários de pior e melhor caso por loja

Classificador para 284 mil transferências com apenas 492 fraudes (0,17%), um caso extremo de desbalanceamento.

95% de precisão e 79% de recall nas fraudes (Random Forest)

  • Python
  • Scikit-learn
  • XGBoost
  • LightGBM
  • Random Forest
Ver estudo de caso
Problema
Golpes com dados bancários pela internet cresceram 43% no Brasil (iG, 2020), gerando prejuízo para a instituição e para os clientes.
Solução
Comparação de Random Forest, XGBoost e LightGBM com ajuste de hiperparâmetros e de threshold, priorizando precisão e recall.
Destaques
  • Random Forest final: precisão 95,06%, recall 78,57%
  • F1-score de 81,97% (XGBoost)
  • Recomendação de modelo conforme a capacidade do time
