  • Databricks
  • Delta Lake
  • Unity Catalog
  • PySpark
  • Spark SQL
  • Scikit-learn
  • MLflow
  • Model Serving
Ver estudo de caso
Problema
O preço precisa ser calculado antes da corrida, e o time recebeu o ticket 3752-RETREINO: avaliar se o algoritmo atual deve ser re-treinado.
Solução
CSV num Volume do Unity Catalog, tabela Delta, features em SQL e PySpark (distância haversine como UDF), pipeline scikit-learn com KNN, registro no MLflow e publicação como API no Model Serving.
Destaques
  • Correlação de 0,97 entre distância e preço
  • Uma regressão linear só com a distância erraria R$ 0,62, cerca de 1/3 do KNN: a recomendação para o re-treino
  • Variáveis conhecidas só depois da corrida (duração, odômetro) excluídas para evitar vazamento
